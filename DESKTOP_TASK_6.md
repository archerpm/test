# Задание № 6 для локальной сессии: недостающие прямые ссылки на подачу заявлений

Контекст: в сервисе (`app/src/data/measures.json`, сводная таблица в `DOCUMENTS.md`) у каждой меры должна быть ссылка на страницу, **откуда подаётся заявление онлайн**, а если онлайн-подачи нет — на страницу с описанием процедуры. Для ряда мер прямой ссылки на саму услугу нет. Нужно найти их в браузере на вашем компьютере (пользователь входит в mos.ru и Госуслуги сам).

## Жёсткие правила (как в задании № 5)
- Вход выполняет пользователь. Логины, пароли, коды не вводить и не запрашивать.
- Заявления **не отправлять**; «Подать», «Отправить», «Подписать» не нажимать. Форму можно открыть и прочитать первый экран, затем закрыть без сохранения; созданные черновики не оставлять (если создался — сообщить, где его удалить).
- Личные данные (ФИО, СНИЛС, паспорт, адреса, номера заявлений) не записывать в отчёт и репозиторий.
- Ссылки брать только то, что реально открыли в браузере; «похожие» адреса не придумывать и не подбирать перебором. Нет подтверждения — «не найдено».

## Что нужно найти (по приоритету)

Для каждой услуги записать: **точный URL услуги** (после перенаправлений, без служебных параметров сессии), **заголовок страницы/услуги (как на экране)**, открывается ли без входа или после входа, и **есть ли онлайн-подача** (кнопка «Получить услугу» / «Начать»).

### Госуслуги
1. **Технические средства реабилитации (ТСР)** для ребёнка-инвалида — услуга «Подать заявку на получение ТСР / компенсацию за самостоятельно приобретённое ТСР» (раздел Госуслуг для инвалидов: `https://www.gosuslugi.ru/invalidam/rehabilitation`). Нужен прямой URL формы (вида `gosuslugi.ru/NNNNNN/1/form`) для: (а) получения ТСР; (б) компенсации за самостоятельно купленное ТСР, если это отдельная услуга.
2. **Компенсация стоимости полиса ОСАГО** гражданам с инвалидностью / родителям детей-инвалидов: есть ли отдельная услуга на Госуслугах (или заявление подаётся через СФР/МФЦ) — URL услуги или фраза с её страницы о том, как подать.
3. **Досрочная страховая пенсия по старости родителю ребёнка-инвалида с детства**: прямой URL услуги «Назначение пенсии» / «Заявление о назначении страховой пенсии по старости» на Госуслугах (и отметить, можно ли выбрать основание «родитель инвалида с детства»); если услуга общая — URL общей услуги.
4. **Бесплатная парковка для инвалидов / родителей детей-инвалидов** на Госуслугах («Оформить бесплатную парковку» / «Скачать знак «Инвалид»»): прямые URL услуг (не раздела `invalidam/transport`).
5. **Дополнительные оплачиваемые выходные для ухода за ребёнком-инвалидом** — есть ли услуга для работника на Госуслугах/СФР (или только заявление работодателю). Если нет, найти страницу СФР или Минтруда с описанием порядка (проверить, что открывается).
6. **Санаторно-курортная путёвка (СФР, жители других регионов)** — подтвердить, что `https://www.gosuslugi.ru/611287/1/form` открывается и как называется.
7. **Заявление об отказе от НСУ** — подтвердить, что `https://www.gosuslugi.ru/600116/1/form` (с `/1/form`) открывается; **Доставка пенсии** — `https://www.gosuslugi.ru/600109/1/form`.

### mos.ru
8. **Лекарства для детей-инвалидов (Москва)** — есть ли услуга онлайн (например, «Запись к врачу для выписки льготного рецепта» или «Электронный рецепт») — URL услуги записи к врачу в поликлинику ДЗМ; страница «Мои рецепты» (раздел электронной медкарты) — только название раздела и URL, без данных.
9. **Адресная социальная помощь / электронный социальный сертификат** — есть ли онлайн-услуга на mos.ru («Получение адресной социальной помощи», «Электронный социальный сертификат»): URL услуги и заголовок; если подача только в МФЦ — URL страницы записи в МФЦ «Мои документы» (`https://www.mos.ru/pgu/ru/app/oiv/onlinebooking/`, проверить, открывается ли) и сведения о центре.
10. **Центр «Мой семейный центр» / «Роза ветров»** — рабочая публичная страница (если сайт `мойсемейныйцентр.москва` не открывается из-за сертификата): официальная карточка на mos.ru или dszn.ru, и адрес записи на приём.
11. **Социальный контракт** (нужен для адресной помощи по 213-ПП): URL услуги на mos.ru/«Моя карьера».
12. **Капремонт:** есть ли в форме ЖКУ (`https://www.mos.ru/pgu2/105201`, шаги 2–9) отдельный пункт про капремонт — только прочитать названия шагов до ввода данных; если нельзя без ввода кода плательщика — так и записать.
13. **Резидентное разрешение парковки**: подтвердить, есть ли в услуге `https://www.mos.ru/pgu/ru/application/dtis/060114/` категории льготников (читать только описание/первые экраны).

### Налоговая и прочее
14. **Личный кабинет налогоплательщика ФЛ** (`https://lkfl2.nalog.ru/lkfl/`): в каком разделе подаётся «Заявление о предоставлении налоговой льготы по транспортному налогу, земельному налогу, налогу на имущество физических лиц» (название раздела/сервиса и URL, если он публичный) и «Заявление на вычет» (стандартный вычет у работодателя — через работодателя; социальный — декларация 3-НДФЛ / «Подтверждение права на вычет»).
