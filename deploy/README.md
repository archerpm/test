# Развёртывание на VPS в Москве

Что получится: сайт на вашем сервере (данные остаются в РФ), офлайн-режим и установка как приложение, еженедельная проверка ссылок **с российского адреса** (без предупреждений «сайт закрыт для зарубежных адресов»).

Сервер: Ubuntu 22.04/24.04 (у вас nginx 1.24 — это Ubuntu 24.04).

## 0. Нужно от вас
1. **Домен** (рекомендую): PWA/офлайн-режим и копирование в буфер работают только по HTTPS, а бесплатный сертификат Let's Encrypt выдаётся на домен. Без домена сайт откроется по `http://IP/`, но офлайн-режим и установка как приложение не включатся. Домен `.ru` стоит около 200 руб./год; запись A должна указывать на IP сервера.
2. SSH-доступ. **Пароли и ключи в чат не присылайте.** Все команды выполняете вы сами.

## 1. Разовая настройка сервера
Войдите по SSH (`ssh root@IP`) и выполните:
```bash
git clone -b claude/disability-benefit-docs-prompt-iz6iae https://github.com/archerpm/test.git /root/posobie
cd /root/posobie/deploy
# свой публичный ключ можно взять на своём компьютере: type %USERPROFILE%\.ssh\id_ed25519.pub
sudo DOMAIN=ваш-домен.ru DEPLOY_PUBKEY="ssh-ed25519 AAAA… комментарий" bash setup-server.sh
```
Скрипт: ставит nginx и Node, создаёт пользователя `deploy` (без пароля, только для выкладки), подключает конфиг с заголовками безопасности, убирает заглушку «404 Not Found», включает недельную проверку ссылок. Запускать повторно безопасно.

Нет ключа на компьютере? В PowerShell: `ssh-keygen -t ed25519`, затем `type $env:USERPROFILE\.ssh\id_ed25519.pub`.

## 2. HTTPS (нужен домен)
```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d ваш-домен.ru
```
Затем в `/etc/nginx/snippets/posobie-headers.conf` раскомментируйте строку `Strict-Transport-Security` и выполните `nginx -t && systemctl reload nginx`.

## 3. Выкладка сайта
С вашего компьютера, из папки проекта (`D:\AI\Posob\test`):
- **Windows (PowerShell):** `.\deploy\deploy.ps1 -Target deploy@IP_или_домен`
- **Linux/macOS/Git Bash:** `./deploy/deploy.sh deploy@IP_или_домен`

Скрипт собирает приложение, прогоняет тесты, выкладывает сайт в `/var/www/posobie` и скрипты проверки в `/opt/posobie-tools`. Повторный запуск обновляет сайт.

### Автоматически из GitHub (по желанию)
В репозитории: Settings → Secrets and variables → Actions → добавьте `VPS_HOST`, `VPS_USER` (`deploy`), `VPS_SSH_KEY` (приватный ключ **отдельный, только для выкладки**), при нестандартном порту `VPS_PORT`. Добавьте также переменную репозитория `DEPLOY_VPS` = `true` (Variables). После этого каждое слияние в `main` обновляет сайт (`.github/workflows/deploy-vps.yml`).

## 4. Проверка ссылок
Раз в неделю (понедельник, 06:00 по Москве) сервер проверяет все ссылки и свежесть данных. Отчёт: `http://ваш-домен.ru/status/links.txt`. Запустить сейчас: `sudo systemctl start posobie-links.service`, затем открыть отчёт. Предупреждения «закрыт для зарубежных адресов» должны исчезнуть; останутся только страницы, которые просят вход.

## Безопасность
- Приложение статическое: нет баз данных, форм отправки и личных данных на сервере. Ответы остаются в браузере пользователя.
- В `posobie-headers.conf` включены CSP и другие заголовки. После изменений проверьте в браузере, что сайт работает.
- Закройте вход по паролю: в `/etc/ssh/sshd_config` `PasswordAuthentication no` (после проверки входа по ключу), включите `ufw allow OpenSSH` и `ufw enable`.
- Обновляйте систему: `apt update && apt upgrade`; включите автообновления безопасности: `apt install unattended-upgrades`.
