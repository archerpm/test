# Выкладка на VPS в Москве (одна команда)

Результат: сайт на вашем сервере (данные остаются в РФ), заголовки безопасности (CSP), недельная проверка ссылок **с российского адреса** (без предупреждений «закрыт для зарубежных адресов»), офлайн-режим и установка как приложение (при наличии домена и HTTPS).

Сервер: Ubuntu 22.04/24.04 с доступом по SSH. Ничего заранее настраивать не нужно: nginx, Node и всё остальное скрипт поставит сам.

## Что нужно на вашем компьютере
- Node.js 18+ (`node -v`), Git.
- Windows 10/11: встроенные `ssh`, `scp`, `tar` (проверка: `ssh -V`). Linux/macOS/Git Bash: то же.
- Папка проекта, например `D:\AI\Posob\test` (`git pull`, чтобы был последний код).

## Выкладка
В PowerShell, из папки проекта:
```powershell
.\deploy\ship.ps1 -Target root@IP_СЕРВЕРА
```
Linux/macOS/Git Bash: `./deploy/ship.sh root@IP_СЕРВЕРА`.

Скрипт: собирает приложение и прогоняет тесты → упаковывает → отправляет на сервер (**два раза спросит пароль или ключ в вашем окне**, никуда его не сохраняет) → на сервере ставит nginx и Node, раскладывает сайт, включает заголовки безопасности, недельную проверку ссылок, убирает заглушку «404 Not Found», делает самопроверку и первую проверку ссылок. В конце печатает адреса сайта и отчёта.

Повторный запуск той же командой обновляет сайт.

Параметры: `-Port 2222` (нестандартный порт SSH), `-Domain ваш-домен.ru`, `-CertbotEmail почта@…` (выпустить бесплатный HTTPS-сертификат; домен должен уже указывать на IP сервера), `-SkipTests`, `-BundleOnly` (только собрать пакет). У `ship.sh`: `-p`, `-d`, `--certbot почта`, `--skip-tests`, `--bundle-only`.

Если вход не под root, а под пользователем с sudo: `-Target ваш_пользователь@IP`. Установка сама вызовет `sudo`.

## Вход по ключу (без пароля; нужен, если выкладку запускает локальная сессия Claude)
Один раз, в PowerShell (пароль вводите вы, в своём окне):
```powershell
ssh-keygen -t ed25519 -f $env:USERPROFILE\.ssh\posobie_deploy -N '""'
type $env:USERPROFILE\.ssh\posobie_deploy.pub | ssh root@IP_СЕРВЕРА "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```
Затем выкладка без пароля:
```powershell
.\deploy\ship.ps1 -Target root@IP_СЕРВЕРА -Identity $env:USERPROFILE\.ssh\posobie_deploy
```
После работы удалите этот ключ с сервера (строку с комментарием в `~/.ssh/authorized_keys`) и смените пароль.

## Домен и HTTPS
Без домена сайт открывается по `http://IP/`, но **офлайн-режим, установка как приложения и копирование в буфер не работают**: браузеры разрешают их только по HTTPS. Бесплатный сертификат Let's Encrypt выдаётся на домен (`.ru` — около 200 руб./год, запись A на IP сервера). Затем:
```powershell
.\deploy\ship.ps1 -Target root@IP -Domain ваш-домен.ru -CertbotEmail почта@mail.ru
```

## Проверка ссылок
Каждый понедельник в 06:00 по Москве. Отчёт: `http://ваш-сайт/status/links.txt`. Сразу: `systemctl start posobie-links.service`. Остаться должны только страницы, которые просят вход. Отчёт публичный, в нём только адреса из `measures.json`.

## Безопасность
- Сайт статический: нет баз данных, форм отправки и личных данных на сервере. Ответы остаются в браузере пользователя.
- Чтобы не работать под root: создайте пользователя с sudo и вход по ключу (`ssh-copy-id`), затем отключите вход по паролю (`PasswordAuthentication no` в `/etc/ssh/sshd_config`), включите `ufw allow OpenSSH` и `ufw enable`.
- Обновляйте систему: `apt update && apt upgrade`; автообновления безопасности: `apt install unattended-upgrades`.
- Пароль, ключи и токены **не присылайте в чат и не добавляйте в репозиторий**. Скрипты ничего из этого не хранят.

## Состав
- `ship.ps1`, `ship.sh` — запуск с вашего компьютера.
- `install-bundle.sh` — выполняется на сервере (его запускает `ship`).
- `nginx-posobie.conf`, `posobie-headers.conf` — сайт и заголовки (CSP, nosniff и др.).
- `posobie-links.service`, `posobie-links.timer` — недельная проверка.
