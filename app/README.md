# Помощник по мерам поддержки семьи с ребёнком-инвалидом (Москва)

Веб-сервис без серверной части: опрос → персональный список мер → документы, сроки, ссылки на подачу → печать/PDF.
Все расчёты выполняются в браузере; ответы никуда не отправляются (сохранение в `localStorage` — только по галочке).

## Запуск
```bash
cd app
npm install
npm run dev        # разработка
npm test           # тесты движка правил
npm run build      # статическая сборка в dist/ (подходит для GitHub Pages)
npm run preview    # затем: npm run test:e2e (Playwright: smoke, формы, функции, доступность, офлайн)
```

## Устройство
- `src/data/measures.json` — **меры** (источник правды — `../DOCUMENTS.md`): условия (`eligibility`), документы (`required` / `conditional` / `auto`), сроки, ссылки, основание, дата проверки, статус `confirmed` / `check`.
- `src/data/questions.json` — вопросы опроса с ветвлением (`showIf`).
- `src/engine.ts` — движок: условия `all/any/not` и `q` с `eq/in/gte/gt/lte/lt`; первое подходящее правило задаёт вердикт (`yes` / `maybe` / `later` / `no`); скрытые bool-вопросы считаются «нет»; ближайшая ежегодная дата считается от текущей.
- `src/App.tsx` — интерфейс (крупный шрифт, высокий контраст, чекбоксы документов, печать с раскрытыми карточками).
- Движок и данные не зависят от React — их можно подключить к Telegram-боту без переделки.

## Возможности
- Опрос с ответом «Не знаю» (вывод пересчитывается по всем вариантам; если от ответа зависит результат — мера уходит в «Уточнить»).
- Три раздела результата: **Меры** (с причинами вывода и подсказкой «что если»), **План действий** (по срочности, с отметками), **Все документы** (общий список без повторов с подсказками, где получить).
- Сохранение ответов и отметок на устройстве (по галочке), перенос на другое устройство кодом или файлом.
- Словарик сокращений прямо в тексте (ИПРА, МСЭ, НСУ и др.).
- Офлайн-режим и установка как приложения (PWA).
- Суммы в `src/data/amounts.json`, предупреждения об устаревших сведениях.

Обновление данных: [UPDATING.md](UPDATING.md).

## Как добавить или изменить меру
1. Проверить норму по первоисточнику, обновить `../DOCUMENTS.md` / `../RESEARCH.md`.
2. Правка в `measures.json`: последнее правило в `eligibility` — без `when` (запасное); поставить `checkedAt`; непроверенные условия — `status: "check"`.
3. Добавить тест в `src/engine.test.ts` и запустить `npm test`.

## Бланки и памятки (печать → «Сохранить как PDF»)
- **Заявление о допвыходных (форма 516н)** — единственный бланк, текст которого подтверждён первоисточником (приказ Минтруда от 19.06.2023 № 516н, действует до 01.09.2029): `src/forms/form516n.ts` (формулировки как в приказе) и `Form516n.tsx` (ввод + печать). Данные остаются в браузере.
- **Памятки подачи** для онлайн-форм (выплаты по уходу, РСД, пособие 553-ПП, ЖКУ): поля, вложения, форматы, сроки — по чтению форм 02.10.2026 (`form` в `measures.json`).
- **Не воспроизводятся сознательно:** КНД 1150063 (форма ФНС со штрихкодом; актуальную версию берите на странице ФНС или подавайте через личный кабинет) и приложение 9 к 37-ПП (текст есть только в редакции 2021 г., менялся актами 2022–2023 гг.; опекуны подают в МФЦ, форму выдаёт МФЦ). Бланки МОСГОРСПОРТ — на section.mosgorsport.ru.
- Проверка e2e: `node e2e/forms.mjs` (создаёт PDF заявления).

## Ограничения MVP
Нет загрузки/OCR документов, входа через Госуслуги и напоминаний — см. `../PROMPT.md`.
Суммы и сроки меняются ежегодно (индексация 1 февраля, постановление Москвы о размерах выплат, окно приёма заявок на отдых): после изменения обновляйте `measures.json`.
Сервис — информационный помощник, а не юридическая консультация.
